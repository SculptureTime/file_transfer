# file_transfer

数据传输工具箱（纯前端静态网页应用）。

## 项目介绍

本项目用于在本地浏览器中进行数据与二维码之间的转换，核心目标是离线可用、无需后端、开箱即用。

当前主要功能：

- 二维码生成
- 支持文件输入
- 支持手动输入文本
- 支持分片生成多张二维码
- 支持查看二维码、单张下载、批量下载（多张时 ZIP）
- 二维码解析
- 支持上传一张或多张二维码图片进行解析
- 支持粘贴文本协议内容解析
- 支持解析后下载还原文件

## 当前限制

- 文件输入最大：`20MB`
- 文本输入最大：`20MB`
- 单次二维码总数上限：`10000` 张

超过限制时会在上传或生成阶段直接提示并阻止继续处理。

## 使用说明

### 1. 启动方式

本项目是静态页面，不需要安装依赖或启动服务。

1. 直接用浏览器打开 `index.html`
2. 进入“二维码生成”或“二维码解析”标签页使用

### 2. 二维码生成

1. 选择“文件输入”或“输入文本”
2. 按需设置二维码大小、纠错等级、压缩策略
3. 点击“生成二维码”
4. 可通过以下按钮操作结果：
- “压缩结果”：查看/复制文本结果（在结果较小可展示时）
- “显示二维码”：弹窗查看全部二维码
- “批量下载”：下载全部二维码（多张为 ZIP）

### 3. 二维码解析

1. 上传二维码图片（支持多张）或粘贴文本结果
2. 点击“解码”（文本）或等待图片自动逐张解析
3. 解析成功后可点击“下载文件”还原原始文件

## 注意事项

- 请尽量保证二维码图片清晰、无遮挡、边缘完整（包含白边）。
- 多张二维码解析时，建议使用同一批生成结果，避免混入其他批次图片。
- 大文件会生成大量二维码，生成与解析都可能耗时较长，属于正常现象。
- 本工具为纯前端处理，数据默认只在本地浏览器内存中处理，不会主动上传到服务器。
- 若浏览器内存较小或同时打开大量标签页，处理大体积数据时可能出现性能下降。
